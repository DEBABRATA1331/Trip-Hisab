Google Sheet Connection Guide

Follow these 3 quick steps to link your Google Sheet. It will automatically format tabs for Overview, Group Expenses, Personal Expenses, Kitty Pool, and Settlements!

  1. Create a blank spreadsheet at sheets.new.
  2. Click Extensions ➔ Apps Script in top menu.
  3. Delete any existing lines in Code.gs, paste the code below, and click Save.
  4. Click the blue Deploy ➔ New deployment button. Choose Web app. Set Execute as: Me, Who has access: Anyone. Click Deploy and copy the Web App URL!
